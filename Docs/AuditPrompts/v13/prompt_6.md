## АРХИТЕКТУРНЫЕ ИНВАРИАНТЫ (КАТЕГОРИЧЕСКИ НЕ СЧИТАТЬ ДЕФЕКТАМИ!):
1. **rAF Coalescing тиков котировок (`ui.js:65-105`):**
   - Входящие тики аккумулируются в `pendingTickPrice`, а мутация DOM синхронизируется через строго один `requestAnimationFrame` на кадр дисплея.
   - Применяется `.textContent` вместо `.innerText` (полное устранение Layout Thrashing и Reflow).
   - Сброс `resetLivePriceFlash()` корректно отменяет запланированный `cancelAnimationFrame`.
2. **Защита Canvas от потери контекста GPU (`ui.js:460-487`):**
   - Метод `initCanvasContextLossHandlers()` вызывает `e.preventDefault()` на событии `contextlost` (обязательное требование спецификации HTML5 для последующего восстановления), останавливает цикл анимации и автоматически перезапускает рендер на `contextrestored`.
3. **Скользящее окно свечей O(1) (`ui.js:545-560`):**
   - Массив `aiChartData` строго ограничен последними 30 свечами через `slice(-30)`. Накопление утечек в куче движка V8 исключено.
4. **Устранение 300ms лага нажатий на iOS (`style.css`):**
   - Свойство `touch-action: manipulation` выставлено для всех интерактивных элементов (`html`, `body`, `button`, `.btn-analyze`, `.asset-item` и т.д.).
5. **Тактильный виброотклик `Telegram.WebApp.HapticFeedback`:**
   - Изолирован от тиков WebSocket. Вызывается строго по событиям пользователя и единожды при переходе в фазу «Action Alert» за 0–2 секунды до закрытия свечи.
