## Что говорит реальная статистика

Из твоей базы (6 месяцев, 2500+ голосов):

```
LightGBM:  58.6% ✅  — реально работает
TA:        53.4% ✅  — немного помогает  
SMC:       51.4% ⚪  — почти монетка
OrderFlow: 35.8% ❌  — АКТИВНО ВРЕДИТ
```

Если соединить всё с равными весами: `(58.6 + 53.4 + 51.4 + 35.8) / 4 = 49.8%` — **хуже, чем LightGBM в одиночку!**

Вся архитектура с MetaLearner, AutoCalib, ConfluenceMatrix — это машина которая пытается компенсировать сломанный LightGBM. Теперь когда он починен и показывает **AUC 78%**, большая часть этой сложности стала балластом.

## Почему LightGBM уже умеет всё что делают TA и SMC

Посмотри на SHAP из последнего лога:
```
Explainer: micro_close_pos (+0.45), upper_wick (+0.35), micro_volatility_z (-0.12)
```

`upper_wick` — это и есть геометрия свечи, которую ищет SMC.  
`micro_close_pos` — позиция цены в диапазоне, это и есть Price Action.  
Он **сам научился** находить эти паттерны из 250,000 свечей — без правил, без кода.

TA добавляет RSI/MACD поверх этого. Но LightGBM уже видит сырые цены, из которых RSI вычисляется. Зачем дважды?
